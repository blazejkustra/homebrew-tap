# blazejkustra/tap

Homebrew tap for [Uncut](https://github.com/blazejkustra/uncut), an AI-first video editor for macOS.

```sh
brew install --cask blazejkustra/tap/uncut
```

Or tap and trust it once, then use the short name:

```sh
brew tap blazejkustra/tap
brew trust blazejkustra/tap
brew install --cask uncut
```

`Casks/uncut.rb` is updated automatically when a new Uncut release is published.
